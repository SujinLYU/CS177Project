A little setup.

1. Connect transcription
Copy .env.example to .env and set OPENAI_API_KEY. Restart Pip after saving. The key stays in the desktop process.

2. Allow microphone and computer audio
macOS asks when you start recording. If needed, check System Settings → Privacy & Security → Microphone and Screen & System Audio Recording. When running from an IDE, macOS may attribute access to that IDE; the packaged Pip.app has its own permission descriptions.

3. Check both meters
Speak briefly and play sound from your meeting. Both meters should respond before you rely on the recording. A silent computer channel does not prove capture is working.

How the transcript works
Pip transcribes complete 20-second audio segments. This is periodic transcription, not word-by-word live captions. Speaker names are not identified automatically. Failed segments can be retried without recording again while this window's session remains open.

Keeping your recording
Transcript and task state are saved locally. Raw audio stays in memory until you choose Save audio. New meeting and Quit discard unsaved audio.

Make room for a new conversation?

This replaces the current transcript and task list, and discards audio still in memory. Save anything you want to keep first.
