PIP · CHROME EXTENSION

把 Pip 放进浏览器。

加载扩展后，Pip 会在你正在使用的网页里陪你，点击它就能打开任务侧边栏。演示模式不需要启动服务器。

  1. 在 Chrome 地址栏输入 chrome://extensions。
  2. 开启右上角的 Developer mode / 开发者模式。
  3. 点击 Load unpacked / 加载已解压的扩展程序，选择本项目里的 extension 文件夹。这个文件夹内应当直接包含 manifest.json。
  4. 打开右上角拼图菜单，把 Pip 固定到工具栏。
  5. 进入一个普通网页，点击工具栏里的 Pip：网页上会出现可拖动的宠物，同时打开任务侧边栏。
加载的是 extension 文件夹，不是项目根目录。

宠物不能出现在 Chrome 设置页、新标签页或 Chrome Web Store 等受限页面。刷新网页后，点击工具栏图标可以再次唤起。

当前版本可以分析示例会议、审核建议并准备本地草稿。真实 AI 模式需要另外启动本地服务并配置 API key，详见项目 README。
